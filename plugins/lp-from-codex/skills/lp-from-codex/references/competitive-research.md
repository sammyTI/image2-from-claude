# 競合調査フェーズ（Step 0.5）

LP制作に入る前に、同ジャンルの先行事例を3〜5本集めて参考にする。
Codex に渡す材料が増えるほど、ジャンル定石・配色・コピーの勝ちパターンを再現しやすい。

## 1. 調査クエリの作り方

ヒアリングで得たジャンル・商品カテゴリから検索クエリを組む。

| ヒアリング | クエリ例 |
|------------|----------|
| エイジング美容液 | `エイジング 美容液 LP`、`美容液 ランディングページ 申込`、`スキンケア トライアル LP デザイン` |
| BtoB SaaS | `SaaS LP 資料請求`、`{業界名} クラウドサービス ランディングページ` |
| セミナー | `{テーマ} オンラインセミナー LP`、`ウェビナー 申込ページ デザイン` |
| 占い | `占い LP`、`鑑定 申込ページ`、`スピリチュアル ランディングページ` |
| LINE登録誘導 | `{ジャンル} LINE登録 LP`、`LINE特典 ランディングページ` |

検索エンジンは Google を想定。クエリは3〜5パターン投げてヒット率を上げる。

## 2. WebSearch / WebFetch の使い分け

- **WebSearch**: 検索結果一覧から候補URLを5〜10件抽出
- **WebFetch**: 候補URLの中身を取得（HTML→要点抽出）
- **Playwright MCP（任意）**: スクショ取りたいときだけ

候補URLは「実在のLP」か「LP紹介・まとめ記事」か区別する。後者はリンクをさらに辿る。

## 3. 抽出する観点（チェックリスト）

各事例から以下を1事例につき1段落でまとめる:

```
## 事例N: {URL or タイトル}

- 業界 / 商品: {何のLPか}
- FV見出し: {一語で}
- FVサブ: {一語で}
- FVビジュアル: {人物 / 商品 / 図解 / 抽象 など}
- 配色: {主3色を HEX or 名前で}
- 構成: {FV → 悩み共感 → ... → CTA、何セクションか}
- 訴求パターン: {社会的証明 / 限定オファー / 比較表 / 体験談 / 専門家推薦 / 数字訴求 など、使われてるもの}
- CTAボタン文言: {正確な言い回し}
- 特徴的な要素: {他にはない仕掛け、あれば}
- 参考になる点: {作る LP に取り込みたい要素}
- 真似しない点: {ブランド毀損リスク / 違法スレスレ / コピペ感のあるもの}
```

## 5. ユーザー確認の聞き方

調査が終わったら、`AskUserQuestion` で以下を聞く:

```
3〜5本の同ジャンルLPを調査しました（{output_dir}/_competitive.md にまとめてあります）。
方針を選んでください:

1. 寄せる: 競合の勝ちパターンに沿った構成・配色・訴求で作る
2. 独自: 競合は参考程度。自分のブランドトーンで独自に作る
3. 一部採用: {具体的な要素}だけ取り入れて、他は独自

3 を選ぶ場合、採用する要素を教えてください。
```

## 6. Codex プロンプトへの組み込み方

選ばれた方針を invocation.md のテンプレに追加する：

```
【競合調査からの参考要素】
- 配色トーン: {決定}
- FV訴求パターン: {決定}
- CTA文言の方向性: {決定}
- 採用する構成順: {決定}
- 避けるべきパターン: {NG項目}

これらを踏まえてスライス画像を生成してください。
ただし、コピペにはしない。あくまで「ジャンル定石を参考にした、自社らしいLP」を目指す。
```

## 7. スキップ条件

以下に該当する場合はスキップしてOK:

- ユーザーが既に明確な参考デザインを持っている
- 急ぎ（30分以内に納品など）
- 完全に独自路線で行きたいとオーナーが明言している
- 過去に同ジャンルで複数作成しており、データが蓄積されている

スキップする場合は `_competitive.md` を作らず、Step 1 に直接進む。

## 8. 倫理ライン

- スクリーンショットは保存OKだが配布物には載せない
- コピーの完全模倣は禁止（参考にしつつ自社らしさを足す）
- 競合のブランド名・ロゴを成果物に含めない
- 第三者のLPをそのまま自分の事例として転載しない
