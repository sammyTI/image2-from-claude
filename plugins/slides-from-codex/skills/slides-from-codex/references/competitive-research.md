# 競合調査フェーズ（Step 0.5）

スライド制作に入る前に、同ジャンルのデッキを3〜5本集めて参考にする。
Codex に渡す材料が増えるほど、ジャンル定石・1枚目フック・タイポの勝ちパターンを再現しやすい。

## 1. 調査クエリの作り方

ヒアリングで得たデッキの目的・テーマから検索クエリを組む。

| 用途 | クエリ例 |
|------|----------|
| セミナー / プレゼン | `{テーマ} プレゼン スライド`、`{テーマ} 講演 資料`、`SlideShare {テーマ}` |
| カルーセル投稿 | `Instagram カルーセル {テーマ}`、`X スレッド カルーセル {テーマ}`、`LinkedIn カルーセル {業界}` |
| 提案書 | `{業界} 提案書 サンプル`、`{サービス} 営業資料 デザイン` |
| 説明資料 | `{商品カテゴリ} 説明 スライド`、`サービス紹介 資料 デザイン` |
| 教育コンテンツ | `{テーマ} 講座 スライド`、`{資格名} 学習スライド` |

## 2. 検索先の優先順位

| ソース | 強み | 向き |
|--------|------|------|
| SlideShare | プレゼン資料が豊富 | セミナー / 提案書 |
| Speaker Deck | エンジニア・テック系 | 技術プレゼン |
| Pinterest | デザインインスピレーション | ビジュアル参考 |
| Instagram / X | カルーセル投稿 | SNS用 |
| LinkedIn | BtoB / 業界系 | プロフェッショナル系 |
| Behance / Dribbble | デザイン特化 | アート寄り |

## 3. WebSearch / WebFetch の使い分け

- **WebSearch**: 検索結果一覧から候補URLを5〜10件抽出
- **WebFetch**: 候補URLの中身を取得
- **Playwright MCP**: SlideShare 等で動的レンダリングが必要な場合のスクショ
- **Instagram / X**: それぞれの harness MCP（mcp__ig-harness / mcp__x-harness）で取得

## 4. 抽出する観点（チェックリスト）

各事例から以下を1事例につき1段落でまとめる:

```
## 事例N: {URL or タイトル}

- テーマ / 用途: {何のスライドか}
- 1枚目フック: {正確な言い回し、引きの強さ}
- 構成: {何枚？ どんな流れ？}
- 配色: {主3色を HEX or 名前で}
- タイポグラフィ: {セリフ / サンセリフ / 太字 / 細字}
- ビジュアル要素: {図解 / 写真 / イラスト / アイコン / グラフ}
- 1スライド1メッセージか、情報密度高めか
- CTA / 締めスライド: {あれば内容、なければ「なし」}
- 参考になる点: {作るデッキに取り込みたい要素}
- 真似しない点: {古臭い / 情報過多 / ブランド毀損リスク}
```

## 5. 出力先

`{output_dir}/_competitive.md` に整理して保存する。

```markdown

検索クエリ: {使ったクエリ一覧}

---

## 事例3: ...

---

## まとめ：採用する勝ちパターン

- 配色: {決定した方向性}
- 1枚目フック: {採用する型}
- 1スライド情報密度: {ミニマル / 標準 / 情報濃いめ}
- タイポグラフィ: {決定}
```

## 6. ユーザー確認の聞き方

調査が終わったら `AskUserQuestion` で:

```
3〜5本の同ジャンルデッキを調査しました（{output_dir}/_competitive.md にまとめてあります）。
方針を選んでください:

1. 寄せる: 競合の勝ちパターンに沿った構成・配色・タイポで作る
2. 独自: 競合は参考程度。自分のブランドトーンで独自に作る
3. 一部採用: {具体的な要素}だけ取り入れて、他は独自

3 を選ぶ場合、採用する要素を教えてください。
```

## 7. Codex プロンプトへの組み込み方

選ばれた方針を invocation.md のテンプレに追加する：

```
【競合調査からの参考要素】
- 配色トーン: {決定}
- 1枚目フックの型: {決定}
- 情報密度: {ミニマル / 標準 / 濃いめ}
- タイポグラフィ方向性: {決定}
- 避けるべきパターン: {NG項目}

これらを踏まえてスライド画像を生成してください。
ただし、コピペにはしない。「ジャンル定石を参考にした、自社らしいデッキ」を目指す。
```

## 8. カルーセル特化の追加観点

カルーセル投稿（Instagram / X）の場合は以下も見る:

- 1枚目の引きの強さ（数字・問いかけ・逆張り）
- 1〜10枚目の情報量設計（だんだん濃くなるか、最初がピークか）
- 番号表示の位置（控えめ / 主張強め）
- 最終スライドのCTA（保存 / シェア / プロフィール誘導）
- 文字サイズ・余白（スマホで読めるか）

## 9. スキップ条件

以下に該当する場合はスキップしてOK:

- ユーザーが既に明確なデザインシステムを持っている
- 急ぎ（30分以内に納品など）
- 完全に独自路線で行きたいとオーナーが明言している
- 過去に同テーマで複数作成しておりデータが蓄積されている

## 10. 倫理ライン

- スクリーンショットは保存OKだが配布物には載せない
- 文言の完全模倣は禁止
- 競合のブランド名・ロゴを成果物に含めない
- 第三者のスライドをそのまま自分の事例として転載しない
