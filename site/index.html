HOW IT WORKS

使い方の流れ

Claude Code に話しかけるか、スラッシュコマンドを打つだけ。
あとはヒアリング → 自動生成 → 引き取り、まで自動で進みます。

  1. 01

    指示する

    スラッシュコマンドの後にざっくり一言で OK。 参考デザインのパスや CTA 文言など、必要なら追加情報も一文で渡せる。

  2. 02

    自動生成

    Claude Code が Codex MCP を呼び、Image 2.0 でスライス画像を生成。 HTML / CSS の組み立てまで全自動で進む。

  3. 03

    完成

    lp-out/<slug>/ または slides-out/<slug>/ に画像と HTML が一式保存。 そのままブラウザで開けば成果物が確認できる。

必要なもの

INSTALL

インストール

Claude Code を起動して、以下のコマンドを順に実行してください。
その後「LP作って」「スライド作って」と話しかけるとスキルが起動します。

STEP 01
マーケットプレイス追加
/plugin marketplace add sammyTI/image2-from-claude
STEP 02
2スキルをインストール
/plugin install lp-from-codex@image2-from-claude
/plugin install slides-from-codex@image2-from-claude
STEP 03
読み込み
/reload-plugins
SSH エラーが出る場合 
/plugin marketplace add https://github.com/sammyTI/image2-from-claude.git
Codex CLI が入ってない場合 
brew install openai/tap/codex
codex login
注意：Codex（ChatGPT サブスク）の利用枠を消費します

このキットは ChatGPT サブスク内で動きますが、生成のたびに Codex の使用枠を消費します。
無料ではなく「サブスクの枠を使う」点にご注意ください。1回の生成で大きく枠を使うこともあるので、Plus より Pro 推奨です。

PROMPT

推奨：ざっくり指示でOK

スラッシュコマンドの後に、ざっくり一言添えるだけで起動します。
足りない情報は Claude Code が必要なぶんだけヒアリングして埋めてくれます。

💬
/lp-from-codex 化粧品LP作って
このくらいざっくりで大丈夫
目的・ターゲット・参考デザイン・コピーなど、必要な情報は Claude Code が順番にヒアリングして埋めてくれます。
指示文を作り込む必要なし、思いついた瞬間に投げてOK。

TROUBLESHOOTING

よくあるつまずき

mcp__codex__codex が見えないClaude Code を再起動。.mcp.json の codex エントリを確認。
画像生成で API 課金が走るcodex login で ChatGPT アカウントを選び直す。
Image 2.0 がレートリミットサブスク枠の上限。少し時間を置く。
生成画像が 30〜100KB しかないHTML フォールバック疑い。本ツールは1枚目のサイズゲートで自動検知して再投します。
