# Codex MCP 呼び出しテンプレ（スライド版）

`mcp__codex__codex` で gpt-image-2 を使ってスライドを生成するときのプロンプトテンプレ集。

## ツール呼び出しパラメータ（推奨デフォルト）

```
mcp__codex__codex
  prompt: <下記プロンプトテンプレ>
  sandbox: workspace-write
  approval-policy: never
  model: gpt-5.5  または gpt-5.2-codex
  cwd: <output_dir の親ディレクトリ>
```

## プロンプトテンプレ A — 標準デッキ（5〜15枚）

```text
gpt-image-2 (Image 2.0) で 16:9 横長スライドを {N}枚 生成してください。
HTML→PNG レンダリング・Pillow 変換は禁止。すべて gpt-image-2 直接生成。

【出力】
- 各スライド 1024×576 PNG（または 1792×1024 PNG）
- {output_dir}/assets/01-{kind}.png 〜 {N}-{kind}.png に保存

【全スライド共通のデザインシステム】
- 配色: {主配色 例: 白背景＋ネイビーアクセント}
- 雰囲気: {ビジネス／カジュアル／ポップ／ミニマル}
- フォント: 日本語サンセリフ、太字
- 余白: 多め。要素は上下左右に最低80pxのセーフマージン
- 装飾: 控えめ。1スライド1メッセージ
- 写真は使わず、アイコン・イラスト・図解のみ
- 必ず16:9のキャンバス全体を使い切ること

【枚数とコンテンツ】

Slide 01 (cover): 表紙
  - メインタイトル: {title}
  - サブ: {subtitle}
  - 著者: {author}

Slide 02 (agenda): アジェンダ
  - 4〜6項目の番号付きリスト

Slide 03 〜 Slide N-1 (本文): 各セクション
  - 1スライドにつきトピック1つ
  - 見出し + 3〜5項目の箇条書き or 図解
  - 数字を強調 / 比較は左右2分割

Slide N (closing): 締め
  - まとめ3点
  - 次のアクション
  - 連絡先 or CTA

【スライド別の詳細仕様】
{各スライドのコピー一覧をここに}

【完了報告】
- 各スライドのフルパス
- gpt-image-2 で生成したことの証跡（generated_images uuid）
- 1枚あたりのファイルサイズ（1MB以上＝Image 2.0、30〜100KB＝HTMLフォールバック）
```

## プロンプトテンプレ B — カルーセル投稿（Instagram / X 用 / 5〜10枚）

```text
gpt-image-2 (Image 2.0) で SNS カルーセル投稿用スライドを {N}枚 生成してください。
HTML→PNG レンダリング禁止。

【出力】
- 各スライド 1080×1080 (正方形) または 1080×1350 (4:5縦長) PNG
- {output_dir}/assets/01-hook.png 〜 {N}-cta.png に保存

【全スライド共通】
- 配色: {ブランドカラー}
- 雰囲気: ポップ・スワイプしたくなる
- 各スライド右下に「{N}/合計」を控えめに表示
- フォント: 日本語サンセリフ、太字、見出しは大きめ

【スライド構成】

Slide 01 (hook): 引きフック
  - 「えっ、◯◯？」「□□してる人、損してます」みたいな問いかけ or 数字
  - 続きが気になる構成。本文は次スライドへ

Slide 02 〜 Slide N-1 (本文): 1スライド1メッセージ
  - 見出し + 短い本文（30〜60字）
  - 図解・アイコン・チェックリストで視覚化

Slide N (cta): 保存・シェアCTA
  - 「保存しておくと役立つよ」「いいねで他にも届けます」みたいな1行
  - プロフィール誘導 or リンク誘導

【スライド別の詳細仕様】
{各スライドのコピー一覧をここに}
```

## プロンプトテンプレ C — 修正フェーズ

特定スライドだけ再生成したいとき:

```text
前回生成した {output_dir}/assets/ のうち、以下のスライドを修正してください。

【対象】
- {slide-NN-purpose.png}

【修正指示】
{修正内容を具体的に}

【他のスライドへの波及】
他のスライドとデザインシステム（配色・余白・トーン）が揃うように、必要なら他のスライドも合わせて再生成してください。

修正後、変更したスライドのフルパスと gpt-image-2 生成証跡を報告してください。
```

## サイズの選び方

| 用途 | 推奨サイズ | アスペクト比 |
|------|----------|-----------|
| プレゼン用デッキ（PCで再生） | 1792×1024 | 16:9 |
| 軽量デッキ（Web埋め込み） | 1024×576 | 16:9 |
| Instagram カルーセル | 1080×1080 | 1:1 |
| Instagram カルーセル（縦長） | 1080×1350 | 4:5 |
| X カルーセル（横長） | 1200×675 | 16:9 |
| LinkedIn カルーセル | 1080×1350 | 4:5 |

gpt-image-2 がサポートする生成サイズに合わせて、近い比率で生成 → `sips` 等でリサイズが安全。

## 応答パース

Codex MCP 応答からファイルパス抽出:

```regex
/(\/[^\s`'"]+\.(png|jpg|webp))/g
```

抽出後、Read で実在＋ファイルサイズを確認。1MB前後なら Image 2.0、30〜100KB ならHTMLフォールバック → 修正プロンプトで再投。

## タイムアウト目安

- 5枚: 2〜4分
- 15枚: 8〜15分
- 30枚: 20分〜30分

10分以上応答がなければ `mcp__codex__codex-reply` で続報を待つか、新セッションで再投。
